# Laravel Office Booking Platform

This repository tracks the implementation of a Laravel 11 + Inertia.js booking platform for managing office spaces, rooms, amenities, and reservations. The project uses Laravel Breeze for authentication scaffolding and Tailwind CSS for the UI. Core goals include role-based access control, robust availability checks, and a modern booking experience for members, staff, and admins.
